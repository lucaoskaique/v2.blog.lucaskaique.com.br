  title: "mem0 CLI — Memória de agente em um único comando"

  body: |
    Memória de agente geralmente significa conectar SDKs, subir bancos de dados, construir pipelines de recuperação antes do seu agente lembrar qualquer coisa. O **mem0 CLI** colapsa isso em um único install.

    Armazene uma preferência, busque-a de volta na próxima sessão, escope-a por usuário ou agente para que nada vaze entre tenants. Aceita texto, arquivos ou stdin. Recuperação sub-milissegundo. Saída JSON para que agentes possam chamá-lo como subprocess.

    - **Instalação:** `npm install -g @mem0/cli` ou `pip install mem0-cli`
